Enterprise Course Analytics Engine

A highly advanced, multi-platform intelligence tool designed to mathematically locate, evaluate, and visualize the absolute best educational content on the internet.

The Intelligence Pipeline

1. Deep Extraction

Headless scraping of hidden JSON-LD schema.

2. Mathematical Ranking

Calculating ROI and Euclidean Centroids.

3. AI Synthesis

LLMs generate roadmaps and course duels.

4. Visualization

Rendering Data via NetworkX & Matplotlib.

Semantic Data Mining

Bypasses traditional UI limitations by using Selenium Webdriver and XML Sitemaps to extract live `application/ld+json` metadata from major platforms simultaneously.

Generative AI Integration

Directly integrates with Meta Llama-3 to create dynamic learning roadmaps, evaluate skill-gap relevance, and conduct side-by-side analytical "Course Duels" in real-time.

The 3D Centroid Pick

Recommendations are mathematical, not random. The system calculates Euclidean distances to an "ideal" coordinate (Max Rating + Max Enrollment) in a 3-dimensional array to find the Algorithm Pick.

Degree Centrality

Utilizing NetworkX, the engine builds a graph of Instructors and Courses, analyzing network edges to identify the most authoritative "Hub" creators in any given tech ecosystem.
